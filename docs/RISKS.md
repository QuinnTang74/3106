# 3106 功能风险说明（RISKS.md）

> 本文档汇总 3.2 版本全部新功能的风险档案。每个功能在 App 内同样展示这三段
> （会发生什么 / 最坏情况 / 怎么恢复），展示位置：功能明细页 + 全屏红色风险
> 确认页（长按 1.2 秒确认）。缺一不合入（计划 S 系列的硬性要求）。
>
> 语言版本：本文档为中文主档；App 内文案有 zh-Hans / English / Tiếng Việt
> 三语版本（`Localizable.strings` 的 `risk.*` 键段）。

## 总规则（适用于所有写入类功能）

1. **每次修改前自动备份**：所有写入走 `VerifiedFileWriter`（原位写入保
   inode + 回读哈希校验 + 失败回滚），写入前由 `BackupCenter` 抓取独立快照。
   备份 tab 可随时点击恢复。
2. **iOS 27 防重启反弹**：MobileGestalt 只写设备 CacheExtra 中**已存在**的
   键；新增设备本来没有的键会触发开机缓存合法性校验整包重建（重启即失效）。
   预设库里不适用的预设显示"此设备缺少对应键，不可用"并禁用，而不是盲写。
3. **类型保真**：Boolean 保持 `<true/>`、浮点保持 `<real>`（相机变焦类值被
   写成整数会导致相机取景黑屏——Erosion 上游的真实事故，本项目的
   `GestaltValueKind` / Plist 编辑器均已按 `CFBooleanGetTypeID()` /
   `CFNumberIsFloatType()` 精确分型）。

## 一、清理器（S1）

| 项 | 说明 |
|---|---|
| 范围 | 每个 App 数据容器的 `Library/Caches` 与 `tmp` + 系统崩溃日志。**白名单不扩大**。 |
| 会发生什么 | 立即删除所选目录下的文件；缓存类数据会被对应 App 在下次启动时重建。 |
| 最坏情况 | 个别 App 首次启动变慢或需要重新登录（理论上不应发生——凭据不在 Caches/tmp）；崩溃日志删除后无法再供排查。 |
| 怎么恢复 | 缓存由系统/App 自动重建；崩溃日志不可恢复。清理前确认不再需要日志。 |
| 纵深防御 | 16 条受保护绝对路径黑名单 + (dev,ino) 身份重校验（TOCTOU）+ 三段式确认门 + 逐子项 symlink 容器内校验。 |

## 二、MobileGestalt 预设库（S4）

### 显示类（display）
- **会发生什么**：修改后通常需要重启（或 Respring）生效；只写设备已有的键。
- **最坏情况**：显示行为异常（AOD 亮度/布局不对）、耗电增加；极少数情况需要恢复备份。
- **怎么恢复**：预设页关掉开关，或备份中心恢复写入前快照；重启生效。

### 设备类（device）
- **会发生什么**：影响设置页可见性与系统能力声明，不改硬件。
- **最坏情况**：设置项不出现或行为异常；硬件不支持的功能不会真实生效。
- **怎么恢复**：关开关或恢复快照，重启即可。

### iPad 类（ipad）
- **会发生什么**：需要重启；主要影响设置页可见性。
- **最坏情况**：台前调度布局与目标设备不一致；iPhone 开 iPad 兼容可能出现应用显示异常。
- **怎么恢复**：关开关或恢复快照。

### 智能类（intelligence）
- **会发生什么**：必须重启；Apple Intelligence 还依赖硬件、区域与 Apple 服务端。
- **最坏情况**：功能仍不可用（依赖不满足）、Siri 行为异常；不破坏设备身份。
- **怎么恢复**：关开关或恢复快照，重启。

### 高级类（advanced）⚠️ 高风险，强制全屏红色确认
- **会发生什么**：修改系统级内部旗标（InternalBuild / 内部菜单 / 内部设置包 / SRD），重启生效，影响多个系统服务。
- **最坏情况**：系统不稳定、设置页异常、部分服务崩溃；InternalBuild 可能触发激活相关检查。
- **怎么恢复**：立即关开关并重启；必要时备份中心恢复快照。持续异常时用整机备份恢复。

## 三、区域与 Siri AI（S4）

### 原生 Siri AI（已核实机型，中风险）
- **会发生什么**：国家码/销售区域 → LL/A，写入对应美版监管型号 + AI 旗标；**不伪装硬件**，重启生效。
- **最坏情况**：Apple 服务与激活相关功能可能异常；Face ID 不受影响。
- **怎么恢复**：备份中心恢复写入前快照，重启。

### 实验模式（旧机型，⚠️ 高风险，默认隐藏在"实验功能"开关后）
- **会发生什么**：伪装产品/主板/CPU 型号 + `SiriMode=2`（仅 iOS 27+）。
- **最坏情况**：可能暂时失去 Face ID、系统不稳定、循环重启，甚至需要连电脑恢复设备。**效果未经真机完整验证。**
- **怎么恢复**：备份中心恢复快照并重启；无法进系统时需 DFU 恢复整机备份。
- **护栏**：未知机型直接拒绝写入；机器资格（iPhone 11–17 家族 / 已核实 M4 iPad）在服务层校验，UI 无法绕过。

### 修改流程通用护栏
- 区域三元组（country/region/regulatory）任何一键缺失即拒绝写入。
- 监管型号只能取自已核实映射表（与 GestaltX/YumEdit 公开表一致）。

## 四、监管模式 Supervised Mode（S5）

- **会发生什么**：直接改 ConfigurationProfiles 容器中 `CloudConfigurationDetails.plist` 的 `IsSupervised`，立即写入；退出设置 App 后生效。
- **最坏情况**：**MDM 管理的设备会丢失管理关系**；下次重启可能出现设置引导屏。
- **怎么恢复**：再次切换开关即还原；或备份中心恢复快照。
- **UI 警告**：页脚常驻 MDM 警告；写入前走全屏风险确认。

## 五、应用存档备份（S5）

- **会发生什么**：把 App 的 Documents + Library/Preferences 打包为 `.3106save`；恢复时按 bundleID 重匹配当前容器，先自动快照再整目录替换。
- **最坏情况**：恢复会用存档**覆盖**当前数据——恢复后新增的进度会丢失（恢复前快照可找回）；受保护应用（3106 自身/系统 App）拒绝操作。
- **怎么恢复**：恢复前快照在备份中心；损坏存档会被清单校验拒绝。

## 六、备份体系（S6）

- **自动备份**：默认开启、无开关可关（产品边界）。全部写入路径先快照后写入。
- **全量备份**（`.3106fullbackup`）：打包 Gestalt 缓存 + 配置描述文件 + 补丁工作区 + 备份中心快照索引。恢复前每个目标自动再备份一次。
- **最坏情况**：全量恢复覆盖的是备份时刻的状态——之后的新改动会丢（每目标恢复前快照可找回）。
- **怎么恢复**：备份 tab 一键恢复；损坏归档被清单校验拒绝。

## 七、壁纸 / 拨号键主题 / 补丁（既有功能）

沿用既有机制：主题安装走 `VerifiedFileWriter` 逐文件备份；补丁走
`PatchTransaction` journal 事务（指纹校验 + 失败回滚 + `resetToAppliedState`）；
壁纸安装含 receipt 与回滚。风险说明见各功能页脚注。

## 七、应用迁移与配置备份包（S7/S8）

### S7 双应用文件夹迁移（合并 / 替换 / 转换）

- **会发生什么**：把源应用所选文件夹的内容按所选方式搬运到目标应用——合并（同名覆盖、目标独有保留）、替换（源完全接管、目标独有删除）、转换（两侧原子互换 `RENAME_SWAP`）。默认先为目标应用创建 `.3106save` 存档。
- **最坏情况**：替换模式会**永久删除**目标独有数据；转换不可回滚，中断发生在交换前后时无法自动判断是否已交换（需人工核对）；迁移中途强退留下部分写入状态（可续传续跑）。微信聊天数据库的密钥/schema 兼容性不受本工具控制——文件搬运成功不代表聊天记录可读。
- **怎么恢复**：迁移前自动备份（.3106save 存档）可整包回滚；中断任务在备份页"检查并继续"（快速/深度两档校验）；转换组按提示人工核对后继续。

### S8 配置备份包（.3106cfg 导出/导入/应用）

- **会发生什么**：把应用的 Preferences 打包为 `.3106cfg` 分享；导入（逐文件 SHA-256 校验）后可把配置应用到任意应用（同名覆盖，可选仅保留目标独有）。
- **最坏情况**：应用配置包会用包内 plist 覆盖目标应用同名偏好——错误来源的配置包会让目标应用行为异常或丢失登录态；损坏或被篡改的包在导入校验阶段被整体拒绝。
- **怎么恢复**：应用前目标应用的每个被覆盖文件自动进入备份中心（版本快照，可逐条恢复）；删除配置包不影响已应用的内容。

### S9 应用启动图（SplashBoard 快照替换）

- **会发生什么**：把目标应用容器内 SpringBoard 的启动快照缓存图片替换为用户照片（按每张原分辨率渲染 PNG）；应用包本身不被修改。
- **最坏情况**：替换后启动画面显示异常；系统重新生成快照会覆盖替换效果（属正常回收，不是数据丢失）；个别快照格式不可探测时被跳过。
- **怎么恢复**：每张图片替换前进入备份中心（版本快照）；按组一键恢复；删除快照缓存可让系统全量重建。

### S10 锁屏文字（LockScreenFootnote）

- **会发生什么**：在系统配置描述文件 SharedDeviceConfiguration.plist 写入或清除锁屏底部文字键（单行 ≤256 字符）。
- **最坏情况**：格式异常内容可能导致锁屏该区域显示错乱；系统大版本更新可能重置该键。
- **怎么恢复**：写入前自动备份整个 plist（备份中心版本快照可恢复）；清除文字即回原厂空状态。

### S11 应用通知音替换（3.2.5 rebuild）

- **会发生什么**：把应用容器内指定的通知音文件替换为自定义音频（aiff/aif/caf/m4a/wav，单文件 ≤20MB）；路径来自用户维护的路径表（手动输入容器相对路径）。
- **最坏情况**：音频格式不被应用接受或文件损坏时，该应用可能不再播放通知声；路径写错可能覆盖容器内其它文件（容器包含判定 + 受保护系统路径护栏拦截）。
- **怎么恢复**：替换前原文件自动备份并进入替换记录（左滑一键恢复）；也可在文件浏览器手动还原备份。
