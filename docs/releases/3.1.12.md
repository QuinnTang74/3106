# 3106 3.1.12 测试版（未发布）

发布日期：2026-11-10

3.1.12 是针对 3.1.11 实测日志的修复测试构建，**尚未发布到 GitHub**。

## 3.1.11 日志说明了什么

导入日志是：

```text
wallpaper: extracting 四季双模式.tendies ...
wallpaper: extracted 四季双模式.tendies
wallpaper: import rejected ... error=unsafeArchive
```

`extracted` 已经出现，说明 ZIP 解包成功；失败发生在 `TendiesPackageInspector`。两个包本身也已用 Python 和 3106 自己的 C 解包器验证：444/462 个条目，0 失败。

## 3.1.12 修复

| 问题 | 修复 |
| --- | --- |
| 包检查因单个路径/symlink/路径长度异常整包拒绝 | `validateTree` / `descriptorSources` / `collectDescriptorSources` 改为记录并跳过问题项，不再抛 `unsafeArchive`；新增 `inspecting package root`、`collected N descriptor sources` 日志 |
| tree 能看到 `descriptors`，但布局收集返回空 | tree 收集器去掉 `resourceValues` 条件，只按目录名收集；新增 `tree descriptor candidates=N`；tree 之后再加一次纯路径后缀枚举兜底，日志为 `fallback descriptor candidates=N` |

1. 启动日志第一行是 `app: 3106 3.1.12 (16) launching`。
