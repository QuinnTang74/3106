## 新功能

### 功能主页与固定底栏

- 主页替换为本地“功能”聚合页，不默认加载远程仓库 feed。
- 底栏固定为：功能 / 文件 / 搜索 / 清理 / 壁纸。
- 仓库市场、仓库源、补丁工程、备份中心、致谢与 Respring 收进功能页。
- 新增文案三语（简中 / English / Tiếng Việt）。

### 快速目录（加载提速）

- App Data 与清理器优先从 LaunchServices 数据库构造容器目录，并持久化紧凑缓存与库路径。
- 热启动不再做 6–13 秒文件系统 inode 枚举；数据库不可用时才回退。
- 首次运行目录发现与 API/MCM 并行；MHA 候选在目录完整时跳过。
- 日志新增 `catalog cache load/built`、`app data ready` 与纳秒级耗时。

### 备份中心与安全写入

- 首次触碰的原始文件快照（不可变）、每次修改前版本、手动备份。
- 未完成事务 journal 与启动恢复；备份失败即中止写入。
- `VerifiedFileWriter`：原地写入、保留 inode/xattr、回读摘要校验、失败回滚。
- 补丁、文件替换、文件删除、Plist/Hex 编辑、MG、拨号主题全部接入。

### 扫描控制

- `ScanCoordinator`：进度、剩余时间、隐藏、停止、后台任务。
- 回退枚举改用 `pathleak`（fsgetpath），每 4096 inode 更新进度并响应取消。
- App Data / Cleaner 的文件系统回退均接入。

### 设备定制

- MobileGestalt 安全子集：设备名称、子类型、灵动岛、AOD/AOD Vibrancy、80% 充电上限、开机提示音。
- 只读加载 → 原始缓存备份 → 每次 Apply 版本备份 → 回读校验 → 一键恢复原始。
- 拨号键主题：12 键图片替换、逐文件备份、恢复原始键图。

### 文件工具

- SQLite 只读查看器：表/视图、行、单行、只读 SQL、CSV；在数据库副本上操作。
- Hex 查看/覆写：分页、跳转、查找 hex/text、同长度覆写；编辑上限 64 MB。
- 结构化 Plist 编辑器：根字典、容器导航、叶子类型编辑、条目增删。
- 文件信息、左滑删除、Open As（Plist/SQLite/Hex）。

### 维护与合规

- App Group 缺失启动提示（显式 App ID + App Groups，通配符 profile 不可用）。
- 致谢与许可页；WebKit Respring。
- 崩溃/诊断日志统计与清理（仅 CrashReporter 下指定扩展名）。

### 利用层加固

- 补丁应用/还原前对每个目标父目录单独授权，避免容器根扩展不足。
- worse_query 按设备学习并记住可用的 query flags；token 打不开目标时尝试另一组再记忆。
- 策略矩阵补充 iOS 27.2.1，测试增至 76 项。
