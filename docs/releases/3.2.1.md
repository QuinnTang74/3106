# 3106 v3.2.1 正式版发布说明

发布日期：2026-11-12 ｜ build 19 ｜ 基于 3.2.0（全量功能对齐版）

## 本版亮点

**3.2.0 是一次大改版**——对照 5 个同类项目（WQ Files / Erosion-CN / GestaltX / YumEdit / WQManager）完成全量功能对齐，3.2.1 在其上补充体验细节。以下是相对 3105（本项目的前身）的完整变化。

## 新功能

### MobileGestalt 卡片页（Erosion-CN 同款交互）
- 暂存开关 + 右上「应用」统一写入；每行显示「已暂存」状态
- **Apple 智能激活四要素体检**：销售地区 / 监管型号 / 国行门控 / 端侧 AI 准入，每行「配置 vs 真机实时」对比；状态图标按规则显示（未修改 = 中性、已改且匹配 = 绿勾、不匹配 = 橙色警告、iOS 26 = 红叉）
- 一键恢复原厂（原始备份 + 写入前自动快照，SHA-256 校验）
- 31 条预设（显示 / 设备 / iPad / 智能 / 高级），锁定态开关（原生已开启 = 浅绿锁定防误关；出厂基线保护 = 橙色锁定，强开会破坏照片高质量消除）
- CacheExtra 字段编辑器：8 种类型、plist 导入导出、类型保真（Boolean 保持布尔、相机变焦 Real 保持浮点）

### 任意文件替换（新模块）
- 选应用 → **逐级浏览容器目录** → 选文件 → 勾选「替换前备份原文件」→ 替换
- **替换记录持久化**（重启仍在），左滑一键恢复备份；恢复前自动把当前文件改名暂存（可回滚）
- **替换预设**：保存应用+路径+备份勾选组合，下次一键选用；同一目标重新保存即更新
- 删除操作强制备份；受保护系统路径（Gestalt 缓存 / 配置描述文件 / 钥匙串等）拒绝裸替换
- iOS 26 与 27 双后端可用（漏洞按版本自动选择）

### 备份中心（一级 tab）
- 底栏改为 功能 / 文件 / 搜索 / 清理 / **备份**；壁纸并入功能页
- **全量备份** `.3106fullbackup`：Gestalt 缓存 + 配置描述文件 + 补丁工作区 + 快照索引打包，一键恢复
- 自动备份：所有写入路径先快照后写入（无开关、产品边界）
- 操作时间线：备份 / 恢复 / 清理 / 写入四类事件统一记录

### 区域与 Siri AI
- 区域三元组修改（LL/A）+ 监管型号自动匹配（已核实机型表）
- 原生 Siri AI（不伪装硬件，Face ID 不受影响）/ 实验模式（伪装 + SiriMode=2，iOS 27+，未知机型拒绝）
- 出厂基线保护：Audio Intelligence 出厂为 false，强开会断路照片「高质量」消除（Erosion-CN v0.8.5 真机验证），已锁定

### 系统级
- **监管模式（Supervised Mode）**开关（MDM 警告常驻）
- 应用存档备份：`.3106save` 打包 Documents + Preferences，重装后按 bundleID 重匹配还原
- 清理器安全纵深：16 条受保护路径黑名单、(dev,ino) 身份重校验、三段确认门；测量预算制 + 增量缓存；逐应用清理进度
- 扫描提速：MCM 并行激活、lsd 目录并行探测、pathleak 动态上界、扫描诊断日志
- 软件源：**AltGallery 唯一默认源**（61 个 App），IPA 下载后交分享面板签名
- 更新检查：启动自动检查 + 设置页手动检查

## 相对 3105 的技术改进

| 领域 | 3105 | 3106 |
|---|---|---|
| 漏洞后端 | 单一 bad_query | 按版本自动选择：17/18 kernel · 26.0–26.6.1 bad_query · 26.7+/27 worse_query |
| 写入安全 | 原子写（换 inode） | VerifiedFileWriter 原位写保 inode + 回读哈希 + 失败回滚 + 自动备份 |
| LS 枚举 | 6–13 秒全盘扫描 | lsd 数据库直读（含 26.5 布局）+ 持久化缓存，冷启动秒出 |
| Plist 编辑 | 类型可能坍缩 | CF 类型精确分型（防相机黑屏） |
| 界面 | 原生 List | Erosion 风格卡片流 + 暂存应用 + 风险确认体系 |
| 支持 | 27.3 beta 实验性 | 27.3 beta 1 正式支持（真机验证） |

## 兼容性

| 系统 | 后端 |
|---|---|
| iOS 17.0–18.7.1 | kernel |
| iOS 26.0–26.6.1 | bad_query |
| iOS 26.7–26.7.2 / 27.0–27.3 beta 1 | worse_query |

iOS 26.0–26.6.1 上，依赖系统组容器（MobileGestalt / 监管模式）的功能显示红字横幅；应用容器内的文件替换 / 清理 / 存档备份**全版本可用**。

## 安装

unsigned IPA 需自签（LCSign / Sideloadly / Impactor / Xcode）。**iOS 26.7+ / 27.x 必须保留 App Group entitlement**（Sideloadly 会丢，用 Impactor 或 Xcode）。
