## English

### Highlights

**3.2.0 was the big parity release** — every feature of five comparable
projects (WQ Files, Erosion-CN, GestaltX, YumEdit, WQManager) landed in
3106. 3.2.1 refines the experience on top of it.

### MobileGestalt cards page (Erosion-CN interaction model)

- Staged toggles committed together by the prominent **Apply** button; each
  row shows its staged state; unapplied changes can be discarded as a group.
- **Apple Intelligence 4-element checkup**: sales region / US regulatory
  model / China-model gates / on-device AI admission, each row showing
  *config vs. on-device* values. Row states: unmodified = neutral,
  written & matching = green check, mismatch = orange warning, and on
  iOS 26.0–26.6.1 (bad_query backend, no write path) all four rows render
  a straight **red X**.
- One-tap **factory restore** backed by immutable originals plus a
  pre-write snapshot (SHA-256 verified).
- **31 presets** across display / device / iPad / intelligence / advanced,
  with lock states: natively-enabled slots render pale green and locked
  against accidental disable; factory-false experimental slots are locked
  off with an explanation.
- **CacheExtra field editor**: all 8 plist types (including Array and
  Dictionary via XML fragments), plist import/export, and exact type
  fidelity — a Boolean stays a Boolean, and a camera-zoom Real stays a
  Real (the Erosion upstream bug that black-screened viewfinders).

### Arbitrary file replace (new module)

- Pick an app → **navigate its container directory by directory** → pick
  a file → optionally tick "back up the original" → replace. Works on
  both the iOS 26 (bad_query) and 27 (worse_query) backends — the exploit
  is selected by OS version automatically.
- **Persistent replace log** (survives relaunch); one-tap restore with the
  live file renamed aside first (recoverable); deletes are always backed
  up.
- **Saved presets**: store an app + path + backup-flag combo and re-anchor
  the whole flow with one tap; re-saving the same target updates the
  preset instead of duplicating it.
- **Protected-path rails**: the Gestalt cache, configuration profiles,
  keychain files and system prefixes are refused with localized reasons —
  they have dedicated pages.

### Backup center (new top-level tab)

- The tab bar is now Features / Files / Search / Cleaner / **Backup**;
  wallpapers moved into the feature hub.
- **Full backup** `.3106fullbackup`: Gestalt cache + configuration
  profiles + patch workspace + the snapshot index in one archive with a
  manifest; restore re-backs-up every target before writing.
- **App save backups**: Documents + Library/Preferences packaged as
  `.3106save`; restore re-matches the container by bundle ID after a
  reinstall.
- **Activity timeline**: backup / restore / clean / write events in one
  list.

### Region & Siri AI

- Region triplet (LL/A) + regulatory model auto-matched from the verified
  machine table; only already-existing keys are written (anti-bounce).
- Native Siri AI (no hardware spoofing, Face ID unaffected) / experimental
  mode (spoof + `SiriMode=2`, iOS 27+, unknown machines refused).
- Factory-baseline protection: Audio Intelligence ships false on every
  iPhone/iPad — forcing it breaks photos' high-quality Clean Up
  (Erosion-CN v0.8.5, device-verified). Locked.

### System-level and cleaner

- **Supervised Mode** toggle (MDM warning permanent, full-screen risk
  confirmation).
- **Cleaner defense in depth**: 16-path protected blacklist, (dev,ino)
  identity re-check between scan and clean, three-stage confirmation
  gate; budgeted measurement (12k entries / 0.25s) with an incremental
  size cache; per-app clean progress; cumulative freed-bytes stats.
- **Scan speedups**: parallel MCM activation, concurrent lsd probes,
  dynamic pathleak inode ceiling, scan diagnostics log with a watchdog.
- **Sources**: AltGallery is the sole default source (AltStore-format
  adapter, 61 apps); downloaded IPAs hand off to the share sheet for your
  own signing tool.
- **Update check**: automatic at launch and manual in Settings; new
  versions open GitHub Releases.

### Compatibility

| System | Backend |
| --- | --- |
| iOS 17.0–18.7.1 | kernel |
| iOS 26.0–26.6.1 | bad_query |
| iOS 26.7–26.7.2 / 27.0–27.3 beta 1 | worse_query |

On iOS 26.0–26.6.1 the system-group features (MobileGestalt / Supervised
Mode) show a red in-page banner; app-container file replace, cleaning and
save backups work on **every** supported version.

### Install

The IPA is unsigned and must be signed with your own tool (LCSign /
Sideloadly / Impactor / Xcode). **iOS 26.7+ / 27.x must keep the App Group
entitlement** (Sideloadly drops it; use Impactor or Xcode).

发布日期：2026-11-12 ｜ build 19 ｜ 基于 3.2.0（全量功能对齐版）

### 本版亮点

**3.2.0 是一次大改版**——对照 5 个同类项目（WQ Files / Erosion-CN /
GestaltX / YumEdit / WQManager）完成全量功能对齐，3.2.1 在其上补充体验细节。

### MobileGestalt 卡片页（Erosion-CN 同款交互）

- 暂存开关 + 右上「应用」统一写入；每行显示「已暂存」状态，可整体放弃。
- **Apple 智能激活四要素体检**：销售地区 / 美版监管型号 / 国行门控 /
  端侧 AI 准入，每行「配置 vs 真机实时」对比。状态图标：未修改 = 中性、
  已写入且匹配 = 绿勾、不匹配 = 橙色警告；iOS 26.0–26.6.1（bad_query
  后端，无写入通道）四行直接显示**红色叉号**。
- **一键恢复原厂**：原始备份 + 写入前自动快照，SHA-256 校验。
- **31 条预设**（显示 / 设备 / iPad / 智能 / 高级五类）；锁定态：
  原生已开启 = 浅绿锁定防误关；出厂为 false 的实验槽位 = 橙色锁定并说明。
- **CacheExtra 字段编辑器**：8 种类型（含 Array/Dictionary XML 片段）、
  plist 导入导出、类型保真（Boolean 保持布尔、相机变焦 Real 保持浮点，
  修掉 Erosion 上游导致相机取景黑屏的类型坍缩 bug）。

### 任意文件替换（新模块）

- 选应用 → **逐级浏览容器目录** → 选文件 → 勾选「替换前备份原文件」→
  替换；iOS 26（bad_query）与 27（worse_query）双后端可用，漏洞按系统
  版本自动选择。
- **替换记录持久化**（重启仍在）；一键恢复备份，恢复前把当前文件改名
  暂存（可回滚）；删除操作强制备份。
- **替换预设**：保存应用 + 路径 + 备份勾选组合，下次一键回填；同一目标
  重新保存会更新预设而不是重复添加。
- **受保护路径护栏**：Gestalt 缓存 / 配置描述文件 / 钥匙串 / 系统前缀
  拒绝裸替换（它们有专用功能页）。

### 备份中心（新一级 tab）

- 底栏五项：功能 / 文件 / 搜索 / 清理 / **备份**；壁纸并入功能页。
- **全量备份** `.3106fullbackup`：Gestalt 缓存 + 配置描述文件 + 补丁
  工作区 + 快照索引打包，含清单；恢复前每个目标自动再备份。
- **应用存档备份**：Documents + Library/Preferences 打包 `.3106save`，
  重装后按 bundleID 重匹配容器还原。
- **操作时间线**：备份 / 恢复 / 清理 / 写入四类事件统一记录。

### 区域与 Siri AI

- 区域三元组（LL/A）+ 监管型号自动匹配（已核实机型表）；只写设备已有键
  防重启反弹。
- 原生 Siri AI（不伪装硬件，Face ID 不受影响）/ 实验模式（伪装 +
  `SiriMode=2`，iOS 27+，未知机型拒绝写入）。
- 出厂基线保护：Audio Intelligence 出厂全为 false，强开会断路照片
  「高质量」消除（Erosion-CN v0.8.5 真机验证）。已锁定。

### 系统级与清理器

- **监管模式（Supervised Mode）**开关（MDM 警告常驻 + 全屏风险确认）。
- **清理器安全纵深**：16 条受保护路径黑名单、扫描→清理之间 (dev,ino)
  身份重校验、三段式确认门；测量预算制（12000 项 / 0.25 秒）+ 增量体积
  缓存；逐应用清理进度；累计已释放统计。
- **扫描提速**：MCM 并行激活、lsd 目录并行探测、pathleak 动态 inode
  上界、扫描诊断日志（watchdog）。
- **软件源**：AltGallery 唯一默认源（AltStore 格式适配器，61 个 App）；
  下载的 IPA 交分享面板给你的签名工具。
- **更新检查**：启动自动 + 设置页手动；新版本跳转 GitHub Releases。
