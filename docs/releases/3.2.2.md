# 3.2.2 正式版 · Stable Release Notes

发布日期：2026-11-12 ｜ build 20

## 中文

### 修复

- **MobileGestalt 卡片页暗黑模式**：卡片底色此前写死为白色，暗色主题下文字（动态白色）落在白卡上无法阅读。卡片与药丸按钮底色改为动态语义色——浅色主题保持白卡灰底，暗色主题自动切为深灰卡黑底。

其余功能与 3.2.1 完全一致，无其他改动。

## English

### Fixed

- **Gestalt cards page dark mode**: card backgrounds were hard-coded white, so the dynamic white text became unreadable on dark themes. Card and pill fills now use dynamic semantic colors — white cards on a grey page in light mode, dark grey cards on black in dark mode.

Everything else is identical to 3.2.1; no other changes.

## 安装 / Install

unsigned IPA 需自签（LCSign / Sideloadly / Impactor / Xcode）。
iOS 26.7+ / 27.x 必须保留 App Group entitlement（Sideloadly 会丢，用 Impactor 或 Xcode）。

The IPA is unsigned; sign it yourself (LCSign / Sideloadly / Impactor / Xcode).
iOS 26.7+ / 27.x must keep the App Group entitlement (Sideloadly drops it; use Impactor or Xcode).
