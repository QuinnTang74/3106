# 3.2.3 正式版 · Stable Release Notes

发布日期：2026-11-12 ｜ build 21

## 中文

### 修复

- **`.tendies` 导入在真机上全部失败 `noDescriptors`**（issue #2）：路径包含检查此前依赖软链解析（`resolvingSymlinksInPath()`），真机沙盒内该调用可能提前返回，`/var` 与 `/private/var` 两种拼写无法归一，导致 descriptors 目录被整棵跳过、导入被拒。现在检查接受两侧任意 raw/resolved 拼写组合，不再依赖软链解析；导入入口统一解压根的路径形态；诊断日志同时打印解析前后的两侧路径。

其余功能与 3.2.2 完全一致，无其他改动。

## English

### Fixed

- **Every `.tendies` import failed with `noDescriptors` on device** (issue #2): the path-containment check depended on symlink resolution (`resolvingSymlinksInPath()`), which can stop early inside the device sandbox — `/var` and `/private/var` then failed to canonicalize to the same tree, the `descriptors` directory was skipped wholesale, and the import was rejected. Containment now accepts any combination of raw and resolved spellings on either side and no longer depends on symlink resolution; the import entry point standardizes the extraction root once; the diagnostic log prints raw and resolved paths on both sides.

Everything else is identical to 3.2.2; no other changes.
