## 中文

### 修复

- **`.tendies` 导入在真机上全部失败 `noDescriptors`（issue #3，#2 的续篇）**：真正根因不是路径拼写，而是一个编译期重载决议缺陷——`validExtensionIdentifier` 把 `allowed.contains` 以裸函数引用传给 `allSatisfy`，整模块优化构建下它可解析到不同的 `contains` 重载，对**任何**扩展标识符（包括 `com.apple.WallpaperKit.CollectionsPoster`）静默返回 false，descriptors 目录因此全部被跳过。改为显式闭包调用后，全仓唯一一处该写法已修复；本地与 CI 的策略套件均已覆盖真实标识符断言（188 checks）。
- **清理器全部应用清理失败 `symlinkEscapesContainer`**：安全策略的组件级软链检查从 `/` 开始逐组件 lstat，`/var` 本身就是指向 `/private/var` 的软链，解析结果与未归一化的容器根做前缀比较必然失败——56 个应用 × 每应用 2 目标全部被拒。现在按组件位置区分语义：容器根之上的系统组件只要求解析后仍通向容器根；容器根及以下仍要求解析后留在容器内（逃逸软链依旧拒绝）。
- **诊断增强**：全部日志行携带构建戳（`[3106/3.2.5-24] ...`），设备日志可直接自证构建版本；descriptor 跳过日志追加 `validIdentifier=` / `contained=` 逐项判定与 `dirCanonical=` / `rootCanonical=` 归一形态，复测时单条日志即可定位失败点。

### 其他

- CI 产物哨兵校验：打包后断言二进制含仅当前源码才有的特征串（`validIdentifier=`，实测 16 字节及以上才可靠——Swift `-O` 会内联 ≤15 字节的插值片段），并修复 artifact 上传路径仍硬编码 3.1.4 时代文件名的问题。

## English

### Fixed

- **Every `.tendies` import failed with `noDescriptors` on device** (issue #3, the sequel to #2): the real root cause was not path spelling but a compile-time overload-resolution defect. `validExtensionIdentifier` passed `allowed.contains` to `allSatisfy` as a bare function reference; in whole-module optimized builds that reference can resolve to a different `contains` overload and silently return false for **every** identifier — `com.apple.WallpaperKit.CollectionsPoster` included — so all descriptor directories were skipped. Rewritten as an explicit closure; this was the only occurrence of the pattern in the codebase. Policy suites (local + CI) now assert the real identifier (188 checks).
- **Cleaner failed for every app with `symlinkEscapesContainer`**: the safety policy's component-level symlink walk lstat()s every ancestor from `/`. On iOS `/var` is itself a symlink to `/private/var`, so the resolved form failed the prefix comparison against the uncanonicalized container root — 56 apps × 2 targets all rejected. The walk now distinguishes component positions: system components above the root only need to still lead to the root in resolved space; components at or below the root must still resolve inside it (escape symlinks are still rejected).
- **Diagnostics**: every log line now carries a build stamp (`[3106/3.2.5-24] ...`) so a device log identifies its own binary; the descriptor-skip log adds per-clause results (`validIdentifier=` / `contained=`) and canonical forms (`dirCanonical=` / `rootCanonical=`) so a single line pinpoints the failure.

### Other

- CI artifact sentinel: after packaging, the binary is asserted to contain a string unique to the current source (`validIdentifier=` — verified 16 bytes and above survive; Swift `-O` inlines interpolation fragments ≤ 15 bytes), and the artifact upload path no longer hardcodes the 3.1.4-era filename.
