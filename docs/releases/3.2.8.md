# 3106 3.2.8 正式版

- 版本：**3.2.8**
- 构建：**33**
- 日期：2026-11-20
- 产物：`3106-3.2.8-unsigned.ipa`
- SHA256：`18d652a41ebacd8569a27a4c1b5b5686df656301188202dd8848ea9edaca7918`

本次版本集中修复“数据明明改了但 3106 不显示/不生效”这一类问题，并把 MobileGestalt 的能力位读取从字典扩展到二进制槽位。

## 重点变化

### 1. 沙箱访问缓存自愈

`worse_query` 依赖 App Group 的 `Library/Caches` 交换。此前如果该目录被上一次中断的交换、旧版本或同组其它程序留下的软链占住，恢复逻辑会一直拒绝，交换无法开始，所有授权返回 `-4`（日志 `tried=[]`）。表现为文件浏览器全部“未识别容器”、清理器只统计到 3106 自身。

现在：

- 恢复失败会先做一次“挪开障碍物”的修复：删除 `Caches` 软链、把非目录/无法恢复的 `.wq-caches-preserved` 改名到 `.wq-caches-reset-<id>`、重建普通 `Caches`；**不删除任何用户数据**。
- 授权失败码改为 `-5`，Swift 层按 60 秒节流自动修复并重试一次。
- 设置 → 沙箱诊断新增 **“重置访问缓存”**，幂等，修复后立即重跑探测。

### 2. 地区读取与生效判定

- `RegionInfoFromSysconfig`（`yK+xavym…`）是系统读取的键；`RegionInfo`（`zHeENZu…`）在 iOS 27 上是**非缓存键**，旧工具注入后可能保留旧值。现在 sysconfig 优先。
- 地区页同时显示两个键、当前修改模式（完整美版 / 仅区域代码 / 未切换），两键不一致时给出橙色警告。
- “仅改区域代码 LL”模式保留原厂销售后缀（如 `CH/A`）与原厂监管型号（如 `A3524`），体检卡不再拿美版表格误判，按真机状态显示绿色勾选。

### 3. MobileGestalt CacheData 槽位

硬件与 AI 能力位不在 `CacheExtra` 字典里，而在根字典的 `CacheData` 二进制槽位。此前预设页只读 `CacheExtra`，音频、快门、健康、AI 等开关全部显示“未检测到 / 不适用”。

现在：

- 运行时解析本机 `libMobileGestalt.dylib` 的查询描述符，校验 `CacheUUID`、总长度、有效位与 8 字节对齐。
- 开关状态从槽位读取，写入也改为改槽位字节，不再向 `CacheExtra` 注入不存在的键。
- 新增“影像与健康”分组：Audio Mix、FaceTime 空间音频、空间音频录制、Responsive Shutter、高血压趋势。
- 新增实验性开关：快门静音、双麦并发、局部光影、超取景/P3、相机控制、旧机型电池、CarPlay Ultra、120Hz 触控、助听器、呼吸暂停、美版血氧、户外极限。
- 体检卡的 `green-tea` 改为从 `CacheData` 实时读取。

### 4. 配置描述文件

- **伪监管残留体检**：识别只含 `IsSupervised` / `OrganizationName`、没有 MDM 证书链的 `CloudConfigurationDetails.plist`；可先备份再单独清除，真实 MDM 配置不会被改动。
- **资产铭牌 `AssetTagInformation`**：与锁屏文字同页，支持读取、写入与清除。

### 5. 更新弹窗

- 启动或回到前台发现新版本即弹窗；前台检查间隔为 5 分钟。
- 按钮固定为 **「取消」和「更新」**，不再出现“不再提醒”。
- 点「取消」只关闭本次，不写入任何屏蔽记录，下次仍会提示。

### 6. 芯片判定

- 修正 `DeviceCPU.a10Family`：`0x67CEEE93`（A10 Hurricane），而不是 `0x2C91A47E`（A8 Typhoon）。此前的错误值让“A10 + iOS 17 拒绝内核链”守卫对真 A10 设备失效。
- C 侧 `offsets_init()` 增加同条件第二道拒绝；启动日志新增 `cpu=0x…`。

## 支持矩阵

| 系统 | 范围 | 后端 |
| --- | --- | --- |
| iOS 17 | 17.0–17.7.x | kernel |
| iOS 18 | 18.0–18.7.1 | kernel |
| iOS 26 | 26.0–26.6.1 | `bad_query` |
| iOS 26.7 | 26.7–26.7.2 | `worse_query` |
| iOS 27 | 27.0–27.2 | `worse_query` |
| iOS 27.3 | 仅 beta 1（`24C5037i`） | `worse_query` |

27.3 beta 2（`24C5049d+`）起 Apple 已封堵 `worse_query`，不在支持范围内。

## 安装

- 发布资产为**未签名 IPA**，需自行签名后安装。
- iOS 26.7+ / 27.x 必须保留 **App Group entitlement**；部分签名工具会丢弃，请使用保留该权限的工具。
- iOS 17/18 首次进入后，在主界面顶部点「解锁」手动执行一次内核链；覆盖安装不会重弹引导页。

## 已知限制

- 27.3 beta 2 及以后不支持。
- “仅改区域代码 LL”模式会保留原厂销售后缀与原厂监管型号，这是预期行为。
- CacheData 硬件槽位只在硬件支持时真实生效；不支持的槽位会显示“不适用”，不会伪造能力。
- 更新检查依赖 GitHub 仓库 `QuinnTang74/3106` 的 Latest Release；设备无法访问 GitHub 时不会弹窗。
