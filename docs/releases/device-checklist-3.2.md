# 3.2 真机手动验收清单

> 性能与漏洞路径无法在模拟器复现（依赖 containermanagerd XPC、沙盒扩展、
> 真实 lsd 数据库），以下各项需在真机（iOS 26.x / 27.x 各一台）执行。
> 每项通过打勾；任何一项失败即阻断发布，记录到 review 报告。

## A. 清理器（S1）

- [ ] 扫描 200+ App：列表 2 秒内出现；体积未测出的行显示正常（不闪退、不卡顿）
- [ ] 清理一个 App 的 Caches/tmp → 重启该 App → 数据正常（登录态保留）
- [ ] 清理后重启设备 → 打开清理页 → 体积重新测量（增量缓存失效正确）
- [ ] 清理历史：清理页显示"累计已释放"数字；备份 tab 时间线出现 clean 事件
- [ ] 三段确认：点清理 → 弹窗确认 → 执行；取消时无副作用
- [ ] （26.7+/27.x）worse_query 后端下完成上述全部

## B. 文件页 / APP 序（S2）

- [ ] 冷启动进文件页：缓存有效时列表即时出现，Section 头显示"索引 · X 分钟前更新"
- [ ] 切"按体积排序"：体积列渐进填充（先"·"后数字），排序随测量更新
- [ ] 快速滚动：图标无闪烁；按压行有高亮
- [ ] 功能页：壁纸入口可进、功能完整（导入 .tendies → 安装 → 桌面生效）
- [ ] 底栏 5 tab：功能/文件/搜索/清理/备份；iPad 侧栏同样正确

## C. Gestalt 预设库 / 字段编辑器 / 区域（S4）

- [ ] 预设库 5 个分类全部渲染；不适用的预设显示"不可用"并禁用
- [ ] 开一个低风险预设（如关机音）→ Respring → 设置页出现对应项 → 关掉 → 恢复
- [ ] Advanced 类预设点击 → 全屏红色确认页出现且长按才执行
- [ ] 字段编辑器：搜索/编辑一个 Boolean 字段 → 保存 → 重读类型仍是 Boolean
- [ ] 字段编辑器：编辑一个 Real 字段（如相机相关）→ 保存 → 相机取景不黑屏
- [ ] 字段编辑器：导出 plist → 修改 → 导入 → 值与类型一致
- [ ] 区域页：显示当前国家码/销售区域/监管型号
- [ ] （已核实机型）原生 Siri AI → 重启 → Siri 设置出现 AI 选项 → 恢复快照还原
- [ ] （实验功能开启后）实验模式入口可见；关闭"实验功能"后隐藏
